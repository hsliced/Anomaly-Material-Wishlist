# Historical packages

These original v0.6.3–v0.6.6 ZIPs are development evidence, not the current installation. Use the root `reframework/` files for the v0.6.7 milestone.

The v0.6.3 and v0.6.4 packages came from the supplied handoff; v0.6.5 and v0.6.6 came from the adjacent local project archive. Their bytes are preserved without reconstruction. Filenames describe the archived packages; individual module headers may retain an earlier version. Older behavior and bugs may remain in these snapshots.

All packages are added together in the baseline commit. Their presence does not imply earlier Git commits, tags, or published releases.

Historical screenshots live in [`portfolio/screenshots/history/`](../portfolio/screenshots/history/) and are described in the [screenshot index](../portfolio/screenshot-index.md). The original handoff is retained locally as supporting material; its stale source-recovery warnings are not installation instructions for this verified baseline.
